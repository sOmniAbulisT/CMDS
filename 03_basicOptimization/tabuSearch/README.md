# Tabu Search

This directory implements a deterministic, memory-driven **Tabu Search (TS)** optimization engine built on a hybrid **R / C++ (Rcpp)** architecture. The engine is structured as a generalized combinatorial optimization solver capable of optimizing discrete vector states.

---

## Algorithmic Framework

Unlike Simulated Annealing which explores solution landscapes via stochastic random-walks and probabilistic acceptance, Tabu Search operates on a strict **deterministic neighborhood scanning strategy**. It relies on adaptive short-term memory structures to actively guide the search out of local optima and flat plateaus.

### Core Architectural Components:

1. **Deterministic Neighborhood Sweep ($A - B + C$):**
   At each global iteration, the solver evaluates the complete explicit neighborhood space generated by the move operators.
2. **Tabu List (Short-Term FIFO Memory):**
   Implemented as a bounded-capacity First-In-First-Out (FIFO) queue via `std::deque` in C++. To guarantee non-retrogressive exploration, the list records the **Inverse Move** of the selected transition rather than the active trajectory state.
3. **Global Aspiration Criterion:**
   An exception override logic. If a neighborhood candidate is technically blacklisted by the Tabu List but its execution yields an objective function valuation strictly superior to the historical global ceiling ($f(X_{\text{candidate}}) < f(X_{\text{globalBest}})$), its tabu restriction is instantly revoked.
4. **Graceful Deadlock Termination:**
   A robust defensive guard mechanism. If the valid search space collapses into an empty set ($\emptyset$)—where all local configurations are forbidden and none satisfy the aspiration criteria—the engine interrupts execution gracefully to avoid infinite stalls or memory fault segmentation.

---

##  The Generational Selector Boolean Matrix (`COND`)

The engine's optimization trajectory is governed by a micro-level conditional evaluation for every probed neighborhood candidate ($X_{\text{test}}$). A candidate updates the temporary directional pool ($X_{\text{new}}$) if and only if the following boolean expression holds true:

$\text{COND} = \Big( (\text{move} \notin \text{tabu}) \wedge \big( (f(X_{\text{test}}) < f(X_{\text{new}})) \vee (X_{\text{new}} = \emptyset) \big) \Big) \vee (f(X_{\text{test}}) < f(X_{\text{globalBest}}))$

* **Standard Vector Pathway:** The transition operator is legally permitted (non-tabu) and outperforms the active pool frontrunner.
* **Aspiration Pathway:** The tabu filter is entirely bypassed because the configuration breaks the absolute global historical threshold.

## Execution Workflow

### Prerequisites

A functional C++ compiler toolchain (e.g., Rtools or GCC via WSL) must be 
present, along with the `Rcpp` and `ggplot2` packages installed in the R 
environment.

### Step 1: Execute Optimization Target

Source the master controller routine to compile the C++ source files and execute the primary optimization loops:

```R
source("03_basicOptimizationTechniques\tabuSearch\main.R")
```

This handles cross-language bindings, runs the deterministic optimization sweeps, and flushes serialized tracking matrices into `ts_result.rds`.

### Step 2: Post-Process Performance Visualization

Trigger the visual analytics pipeline to render the generational structural behavior:

```R
source("03_basicOptimizationTechniques\tabuSearch\visualize.R")
```

This maps the step-by-step landscape updates and exports a high-resolution convergence curve profile as `ts_convergence.png`.
